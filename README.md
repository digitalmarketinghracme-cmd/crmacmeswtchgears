# ACME Switchgears CRM

Single-file CRM & ERP (leads, products, quotations, invoices, reports) that runs entirely in the browser.

- `index.html` – the whole app
- Data is stored in each user's browser (localStorage). Use **Settings → Download backup** regularly.

## Host free on GitHub Pages
1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch** → branch `main`, folder `/ (root)` → Save
3. Open `https://<your-username>.github.io/<repo-name>/`
